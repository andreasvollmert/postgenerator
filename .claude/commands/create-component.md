Create a new React component:

1. Ask for the component name and purpose
2. Determine if it needs props, state, or side effects
3. Create the component file with:
   - TypeScript interface for props
   - Functional component with proper typing
   - Exports
4. Follow the existing project structure and patterns
5. Include basic documentation comments if the component is complex
